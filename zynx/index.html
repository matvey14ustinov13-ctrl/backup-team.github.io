Zynx Linux v1.0

A clean, offline Arch Linux installer with XFCE, built by Backup Team.

Zynx Linux is an Arch-based live medium with a graphical installer written in C + GTK3 (no Python, no terminal needed). The installer copies the live system to the target disk, configures the boot loader and creates your user account. The interface and the installed system are in English.

Download the latest release Release notes and SHA256

What you get

  • XFCE Full — Firefox, LibreOffice, GIMP, VLC, printing and media support.
  • XFCE Minimal — XFCE with essential applications only.
  • Console — no graphical desktop; text login, networking and package tools.
  • Login shell for the new user: bash, zsh or fish.
  • A separate /home partition and an optional swap file (0, 2, 4 or 8 GiB).
  • Formatting is off by default; the installer shows the layout it will use.
  • Optional “Make Zynx the default boot entry” switch.
  • Magic SysRq enabled on the live medium and the installed system: Alt + SysRq, then R E I S U B.

Requirements

  • A 64-bit x86 computer, at least 12 GiB of disk space (16 GiB recommended).
  • At least 2 GiB of RAM.
  • A USB drive of 2 GB or more, or a virtual machine.

Write the image to a USB drive

Download the ZIP, extract the ISO and verify it:

sha256sum zynx-YYYY.MM.DD-x86_64.iso

On Linux or macOS:

sudo dd if=zynx-YYYY.MM.DD-x86_64.iso of=/dev/sdX bs=8M status=progress oflag=sync

On Windows use Rufus in DD mode or balenaEtcher.

Install

  1. Boot the medium (UEFI or BIOS) and choose Zynx Linux.
  2. The live desktop logs in automatically as zynx.
  3. Start Install Zynx Linux from the desktop.
  4. Choose edition, shell and disk, then create the user account.
  5. Set the root partition size and the swap file size; select whether Zynx should become the default boot entry.
  6. Review the summary, type the confirmation word and wait for the copy to finish.
  7. Remove the medium and reboot.
Formatting is disabled by default. With formatting disabled the installer reuses the largest existing Linux root partition and keeps your /home. Enable the “Format the disk” switch only if you want a fresh partition table (BIOS boot, ESP, root, /home).

After installation

Log in with the account you created. Administrative tasks use sudo; the root account stays locked unless you set a root password during installation. The system is offline-installed: update it with sudo pacman -Syu.

Источник и сборка

Исходники проекта (профиль archiso, установщик на C, скрипты сборки) находятся в zynx/source. ISO собирается на Arch Linux командой sudo bash build-arch-amdgpu-shell.sh.
